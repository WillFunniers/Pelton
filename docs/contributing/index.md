# Contributing

Pelton is free and open source, and contributions are welcome: code,
translations, documentation, or just a well-written bug report.

!!! tip "New here?"
    It's useful, though not required, to read the
    [Contributing guidelines](guidelines.md) before opening your first PR.

## Ways to contribute

<div class="grid cards" markdown>

-   __Code__

    ---

    Fix a bug or build a feature. See
    [Developing on Pelton](developing.md) to get a dev environment running.

-   __Translations__

    ---

    UI strings live in `frontend/src/lib/locales/`, one file per language.
    See [Translating Pelton](translations.md).

-   __Documentation__

    ---

    This site lives in `docs/` in the main repo and builds with
    [zensical](https://github.com/zensical/zensical). Typo fixes and
    clarifications are welcome via pull request.

-   __Bug reports__

    ---

    Found something broken? See
    [Reporting an issue](../reporting-an-issue.md).

</div>
