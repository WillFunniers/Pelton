## <img src="https://api.iconify.design/tabler/info-circle.svg?color=white" width="26" style="vertical-align: -4px;"> 关于 Pelton

Pelton 是一款现代的自由及开源软件（FOSS）邮件客户端，用 Go 编写、基于 Wails 框架构建。它从底层设计上就以尊重你的数据为前提。我们相信收件箱属于你自己 —— 因此 Pelton 完全没有遥测，完整保护隐私。

## <img src="https://api.iconify.design/tabler/sparkles.svg?color=white" width="26" style="vertical-align: -4px;"> 功能

* <img src="https://api.iconify.design/tabler/shield-lock.svg?color=white" width="18" style="vertical-align: -4px;"> **完整隐私：** 你的数据留在你自己的机器上。零跟踪、零遥测，收件箱完全由你掌控。
* <img src="https://api.iconify.design/tabler/bolt.svg?color=white" width="18" style="vertical-align: -4px;"> **快速搜索：** 立刻找到你要的邮件。搜索引擎针对速度做过优化，处理体积庞大的本地邮箱也游刃有余。
* <img src="https://api.iconify.design/tabler/palette.svg?color=white" width="18" style="vertical-align: -4px;"> **高度可定制：** 把客户端调整成贴合你工作流与审美偏好的样子。见 https://themes.pelton.app
* <img src="https://api.iconify.design/tabler/file-export.svg?color=white" width="18" style="vertical-align: -4px;"> **可携带的配置：** 把整套设置（账号、偏好、自定义布局）导出成单个便于迁移的文件。
* <img src="https://api.iconify.design/tabler/code.svg?color=white" width="18" style="vertical-align: -4px;"> **FOSS 且跨平台：** 真正开源，并在不同操作系统上都有良好表现。
* <img src="https://api.iconify.design/tabler/flag.svg?color=white" width="18" style="vertical-align: -4px;"> **彩色旗标**：八种颜色，默认只保存在本地，也可以选择作为 IMAP 关键字同步到服务器，让其他客户端也能看到。
* <img src="https://api.iconify.design/tabler/eye.svg?color=white" width="18" style="vertical-align: -4px;"> **内置预览器**：PDF、图片以及文本 / 代码 / Markdown 都能直接在 Pelton 里打开，不必离开应用。
* <img src="https://api.iconify.design/tabler/clock.svg?color=white" width="18" style="vertical-align: -4px;"> **稍后提醒（Snooze）**：在右键菜单里用友好的日期时间选择器推迟一封邮件；到点后它会以未读状态重新出现，也可以选择在此之前从收件箱隐藏。
* <img src="https://api.iconify.design/tabler/address-book.svg?color=white" width="18" style="vertical-align: -4px;"> **写信时自动补全通讯录**：从你收发的邮件中学习，并可在设置里管理。
* <img src="https://api.iconify.design/tabler/keyboard.svg?color=white" width="18" style="vertical-align: -4px;"> **Vim 模式**：写信编辑器支持模态编辑；此外全应用都提供**可自定义的键盘快捷键**。

## <img src="https://api.iconify.design/tabler/help-circle.svg?color=white" width="26" style="vertical-align: -4px;"> 常见问题

<details>
<summary><b>Pelton 支持哪些邮箱服务商？</b></summary>
<p>Pelton 支持标准 IMAP 与 SMTP，因此开箱即可用于绝大多数邮箱服务商。我们还为 Gmail 内置了 OAuth2 支持。由于 Pelton 是 FOSS，社区可以很方便地贡献代码，为更多服务商添加支持。</p>
</details>

<details>
<summary><b>Pelton 能离线使用吗？</b></summary>
<p>可以。你可以让 Pelton 在本地缓存最近的邮件（时间范围由你选择），也可以把特定邮件明确标记为永久离线保留。</p>
</details>

<details>
<summary><b>Pelton 支持 PGP/GPG 加密吗？</b></summary>
<p>当然支持！</p>
</details>

<details>
<summary><b>我的数据实际存在哪里？</b></summary>
<p>你的数据完全由你掌控：它保存在本机的 SQLite 数据库里，以及你原有邮箱服务商的服务器上。我们不会托管你的数据，也不会让它经由任何第三方服务器转发。</p>
</details>

<details>
<summary><b>为什么用 Wails + Go，而不是 Electron？</b></summary>
<p>为了速度与内存效率。借助 Go 与 Wails，Pelton 的内存占用明显低于笨重的 Electron 外壳，同时依然提供流畅的跨平台界面。</p>
</details>

<details>
<summary><b>Pelton 如何处理自定义 HTML 跟踪像素与远程图片？</b></summary>
<p>完全可配置。默认会拦截远程图片与跟踪像素（做法与 Thunderbird 类似）。被拦截时会显示一条提示条，你可以在需要时单独放行这一封邮件的图片。</p>
</details>

<details>
<summary><b>我可以自建服务、或把同步用的数据库放到自定义路径吗？</b></summary>
<p>使用自定义数据库路径（例如把 SQLite 指向网络共享）目前还不推荐、也未充分测试，但这个能力很快就会到来。</p>
</details>

<details>
<summary><b>有遥测或自动崩溃上报吗？</b></summary>
<p>没有。Pelton 完全没有遥测。如果你遇到崩溃或缺陷，请帮我们在 GitHub 上手动开一个 issue。</p>
</details>

## <img src="https://api.iconify.design/tabler/tag.svg?color=white" width="26" style="vertical-align: -4px;"> 版本号规则

在 **1.0.9**（含）之前，Pelton 使用语义化版本号；从下一个版本起改用**日历版本号（Calendar Versioning）**，格式为：

```
YYYY.Q.INCR
```

* **YYYY** —— 完整的日历年（例如 `2026`）。
* **Q** —— 日历季度，`1`–`4`（Q1 = 1–3 月，Q2 = 4–6 月，Q3 = 7–9 月，Q4 = 10–12 月）。
* **INCR** —— 该季度内的发布计数。从 `0` 开始，每进入新季度重置为 `0`。

每季度的首个发布（INCR 为 `0`）会省略末尾的 `.0`，因此写成 `YYYY.Q`。例如：

| 发布 | 版本号 |
| --- | --- |
| 2026 年 Q4 的首个发布（旗舰版） | `2026.4` |
| 该季度的下一个发布 | `2026.4.1` |
| 再下一个 | `2026.4.2` |
| 2027 年 Q1 的首个发布 | `2027.1` |
